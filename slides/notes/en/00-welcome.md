<!-- @note: what-you-will-build -->
- CLASH: a small social app for Berlin
- A clash = an activity at a place and a time
- A venue = a place that can host many clashes
- People join; hosts accept or reject; everyone gets notified
- Dashboard: counts, upcoming clashes, popular venues, activity
- Build all of this with Claude Code from a plain-language spec — no starter code

<!-- @note: and-a-live-map -->

- Clicking an empty spot on the map starts a new clash there
