<!-- @note: what-you-will-build -->
Sagen:
- CLASH: eine kleine Social-App für Berlin
- Ein Clash ist eine Aktivität an einem Ort und zu einer Zeit
- Ein Venue ist ein Ort, der viele Clashes beherbergen kann
- Leute treten bei, Hosts akzeptieren oder lehnen ab, alle bekommen eine Benachrichtigung
- Das Dashboard: Zahlen, kommende Clashes, beliebte Venues, Aktivität
- All das baust du mit Claude Code aus einer Spec in einfacher Sprache — ohne Starter-Code

<!-- @note: and-a-live-map -->
Sagen:
- Die Karte ist das Herzstück der App
- Jeder Clash und jedes Venue ist ein Pin
- Ein Klick auf eine leere Stelle der Karte startet dort einen neuen Clash
- Später: Arbeit an der fertigen Referenz-App, Claude Code deutlich stärker fordern
- Das Bild im Kopf behalten — so sieht "fertig" am Ende des Builds aus
